💰 Expense Tracker

A simple command-line Expense Tracker built with Python. This application helps users manage their daily expenses, organize spending by categories, and track their total expenses.

✨ Features

- **Add Expense:** Add a new expense with a title, amount, and category.
- **Show All Expenses:** View all saved expenses.
- **Edit Expense:** Update an existing expense.
- **Delete Expense:** Remove an expense using its ID.
- **Search Expense:** Find an expense by its ID.
- **Total Expenses:** Calculate the total amount of all expenses.
- **Show Categories:** Display available expense categories.
- **Export to CSV:** Export expense data to a CSV file.

## 🛠️ Technologies Used

- Python 3
- JSON (data storage)
- CSV (data export)
- UUID (unique expense IDs)
- Datetime (expense dates)
